# Connect-Hotel Landing Page

Este é um projeto de landing page para o Connect-Hotel, um sistema de gestão hoteleira fictício. O objetivo é apresentar as funcionalidades e vantagens do sistema, incentivando hotéis a adotarem a solução.

## Funcionalidades

* Slide de imagens para destacar as instalações do hotel.
* Seção de perguntas frequentes interativa.
* Design responsivo para visualização em diferentes dispositivos.
* Seções de benefícios, recursos e chamada para ação.
* Footer com informações de contato e links para redes sociais.

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## Como Visualizar

1.  Clone este repositório.
2.  Abra o arquivo `index.html` em seu navegador.

## Estrutura do Projeto

* `index.html`: Arquivo HTML principal.
* `estilo/`: Pasta contendo arquivos CSS e imagens.
    * `estilo.css`: Arquivo de estilos principal.
    * `img/`: Pasta com imagens utilizadas na landing page.
* `script.js`: Arquivo JavaScript com funcionalidades interativas.
